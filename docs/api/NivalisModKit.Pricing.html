Class Pricing

NivalisModKit.dll

Change vendor prices. Handlers adjust Price; the result is what the shop shows and what is actually charged or paid, for the player and for venue managers alike. Nothing is installed until a mod subscribes. Prices are recalculated on every lookup, so a handler can change its rules at any time (for example from a live-reloaded setting).
