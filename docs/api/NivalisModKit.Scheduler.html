Class Scheduler

Namespace
NivalisModKit
Assembly
NivalisModKit.dll

Run code later, on the main thread: next frame, after some game time, at a clock hour, or after some days. Game-time schedules are checked every frame against the clock, so sleeping past the moment still runs them (once, when the clock passes it). Everything pending is cancelled when a save loads or a new game starts; keep longer plans in SaveData.
