How a setting appears in the in-game mod browser. Pass one as a tag when you bind the setting:

Config.Bind("General", "Verbose", false,
    new ConfigDescription("Log every decision.", null, new ModSetting { IsAdvanced = true }));

Listing is opt-in: a setting appears when it has this tag, or when its mod called ListSettings(string) (then all of its settings appear, and these flags adjust them). The browser also reads BepInEx ConfigurationManager's ConfigurationManagerAttributes tag to adjust listed settings, but that tag alone doesn't list a setting.
