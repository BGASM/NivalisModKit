Class SaveData

Namespace
NivalisModKit

NivalisModKit.dll

Data that belongs to one save, stored next to it as <save>.modkit.json. Values are kept per mod and per key, as JSON. Read and set them any time during gameplay; the kit writes the file when the game saves and reads it back when that save loads. A new game starts empty.
