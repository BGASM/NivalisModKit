Named commands that development tools can run in the game through the dev bridge (POST http://127.0.0.1:5710/cmd/name?arg=value, or tools/bridge.sh cmd name arg=value). For test mods and debugging: open a window, set up a situation, read back a result. Commands run on the main thread, so they can use the game and the kit freely. Running them needs the kit's [DevBridge] Enabled and AllowCommands; registering always works and costs nothing.

});

Register(string, string, string, Action<CommandArgs>)

Registers a command. run gets the request's arguments and returns the reply (any object; sent as JSON) or null for "ok". Names are letters, digits, '.', '-' and '_'; a name another mod already registered is refused (returns false, and the log names both mods).
