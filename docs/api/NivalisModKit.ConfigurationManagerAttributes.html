Class ConfigurationManagerAttributes

Namespace
NivalisModKit

NivalisModKit.dll

The standard BepInEx settings tag, read by settings menus such as Mod Settings Menu and Configuration Manager as well as the kit's own Mods browser. Pass one as a tag when you bind a setting:

Config.Bind("Debug", "Verbose", false,
    new ConfigDescription("Log every decision.", null, new ConfigurationManagerAttributes { IsAdvanced = true }));

Menus find it by its class name and read its fields, so this is the same tag mods usually copy into themselves; with the kit you don't need a copy. In the kit's browser it also opts the setting in, like ModSetting. New in 0.6.2.
