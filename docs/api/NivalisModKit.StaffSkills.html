Characters' work skills (cooking, serving, cleaning, managing): who has which, their level, XP and the level's values. A person's skills are XP per skill (RuntimePersonData.Skills); the skill turns XP into a level and the level into its data (CookingLevel.PreparationQuality, ServingLevel.ServiceQuality, ActionSpeed...). The skill definitions are the ones the game's own staff actions use, so they always match what the game reads.

Remarks

How the game uses them: a prep step's time is multiplied by the cook's CookingTime(Person) (lower is faster; CookingLevel.CookingTime since the game's patch 4, ActionSpeed before) and divided by HappinessInfluence(Person). Plating takes a flat 6 seconds since patch 4. Since patch 4 every skill's ActionSpeed is a speed (higher is faster), cooking's included. A plated meal's quality is the plater's PreparationQuality × HappinessInfluence(Person); a waiter adds ServiceQuality × the same influence to the order's service score when taking it and at each delivery. Someone without the skill gets 0.8 quality and a 1.2 time multiplier (in the game only the player can be in that position).
